Infotech Internship Project

Smart City Connect

An Android-based civic issue reporting application designed to help citizens report problems like potholes, garbage accumulation, damaged streetlights, water leakage, traffic issues, and emergency situations.

Project Details

Duration
16 weeks
Platform
Android application
Tools
Android Studio, Java/XML, Firebase
Focus
Smart city governance and citizen reporting

Overview

A digital bridge between citizens and authorities.

Smart City Connect was developed to make civic complaint reporting faster, clearer, and more transparent. Instead of relying on slow manual complaint systems, the application lets citizens submit issue photos, location coordinates, and descriptions directly from their smartphones.

The report positions the project around smart governance, public participation, cleaner cities, safer roads, better infrastructure maintenance, and responsible use of technology for public welfare.

Profile Connection

This project strengthens Maaz's portfolio by connecting electrical and electronics engineering education with practical software development, cloud integration, public safety, and smart city problem solving.

Application Highlights

Core features documented in the report.

Civic Issue Reporting

Users can upload photographs, add descriptions, fetch GPS coordinates, and submit complaints to Firebase.

Secure Authentication

Firebase Authentication supports email/password login and Google Sign-In for easier access and secure sessions.

Complaint Tracking

Submitted issues can be monitored through status stages such as Reported, Assigned, In Progress, and Resolved.

Emergency SOS

Fire, medical, and police emergency modules allow users to share incident evidence and real-time location details.

Firebase Backend

Firestore stores user details, complaints, and SOS requests with real-time cloud synchronization.

Social Impact

The project supports cleaner, safer, more responsive urban communities and aligns with sustainable smart city goals.

Future Scope

Clear paths for scaling the project.

The report identifies future enhancements including AI-based issue classification and prioritization, municipal dashboard integration, IoT sensor connectivity, multilingual support, real-time chat support, advanced analytics, and predictive analysis for urban issues.

Learning Outcomes

The project demonstrates Android app development, Firebase integration, modular system design, secure data handling, teamwork, documentation, testing, and the use of modern engineering tools for a public-service application.
