Getgoing Activity Tracker

Project Overview

Designed around routine progress tracking.

Getgoing helps translate daily activities into visible progress. It is useful as a portfolio project because it shows practical app thinking: input, tracking, feedback, and a clean interface for repeat use.

Profile Connection

The project supports Maaz's broader profile as an engineer who can organize real tasks into structured systems and present them through approachable software interfaces.
