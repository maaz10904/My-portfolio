Featured Project

GetShopping

A shopping web project focused on product discovery, cart interaction, and a clear e-commerce journey from browsing to checkout readiness.

View Repository Back to Case Studies

Project Overview

Built to present a practical retail flow.

GetShopping demonstrates how an online store can organize products, guide users through item selection, and present a polished interface. For a portfolio, it shows Maaz's ability to think about the user journey, not only individual screens.

Profile Connection

This project connects engineering discipline with web presentation: structured workflows, clear information layout, and a practical understanding of how real users move through a system.
