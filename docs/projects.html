Smart City Connect

Internship project: Infotech project work

Smart City Connect is an Android issue reporting application built to help citizens submit civic complaints with photos, GPS coordinates, and descriptions. The project report documents Firebase Authentication, Firestore database storage, complaint tracking, and emergency modules for fire, medical, and police situations.

Key features: civic issue reporting, image upload, GPS location, Google sign-in, complaint status tracking, Firebase backend, and emergency SOS workflows.
